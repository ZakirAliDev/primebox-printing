# Trust / Logo Bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an under-hero trust/logo bar (2 still images + logo carousel) with admin controls, and split Site Settings into Global / Home tabs.

**Architecture:** Extend `siteSettings` with a `trustBar` object (normalize helpers in `src/lib/trust-bar.ts`). Render `TrustBar` on the home page under the hero. Admin editing lives in `TrustBarEditor` on the Home tab of `SiteSettingsForm`. Carousel looping reuses `related-carousel` helpers via slide `id` → `slug` mapping.

**Tech Stack:** Next.js App Router, React client components, Tailwind CSS, existing catalog JSON store + `/admin/api/media` uploads.

## Global Constraints

- Intro text under trust bar stays hardcoded (not admin-editable).
- Promo bar stays in Global settings.
- Each still and each carousel slide: image + optional URL + alt.
- Full carousel controls: autoplay, interval, slidesToShowDesktop, slidesToShowMobile.
- Hide section when both stills empty and carousel has no slides.
- No carousel arrow buttons; pause on hover; respect `prefers-reduced-motion`.
